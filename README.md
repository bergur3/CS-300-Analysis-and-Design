# CS-300-Analysis-and-Design

These two projects are the culmination of my learning in data structures and my choice in implementing the courses program with a Binary Search Tree. The pseudocode that I wrote helped a lot, but only when I coded and worked through the functions for the BST itself was I better able to think about better time efficiency in a worst case. One challenge that happened was figuring out how to improve the worst-case time complexity when the BST is loaded with data. An improvement that I found was focused on how the Course structs are inserted into the BST from a temporary courses vector. I originally sorted them and inserted them sequentially, assuming that was enough. However, this would have resulted in a less-than or completely unbalanced BST performing more like a linked-list. To fix this, I instead inserted the middle element of the vector first, followed by the rest of the elements. I didn’t realize until after submission that this was also flawed, and I should rather have continued to grab the median element from the vector until all were inserted into the BST for the balance I was aiming for. 

Another challenge I encountered was also in the loading process where I verified that each prerequisite of a course existed in the overall data. This felt like the bottleneck where the worst-case time complexity was worsened, since I did nested loops over the entirety of the course vector repeatedly. My attempt at fixing this was leveraging the BST’s search functionality to find the referenced course from the starting prerequisite. If the BST were well balanced then search operations would be O(log n), possibly improving the loading operation’s worst case time complexity. 

These series of assignments where I developed pseudocode and used it to help me develop the code has reinforced how helpful a process it is to write out the functionality without adhering to specific syntax. It helped me think more about the systems and how the data structures worked before I implemented them. These final two projects became an example to me of how I can adapt my notes and pseudocode into more planned and structured programs.
